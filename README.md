# 학급 편성 도우미 (Class Mate) — 학생 특성 기반 학급 편성 프로그램

초등학교 교사가 **학생별 특성·학생 간 관계·학급별 인원·교사가 정한 조건**을 함께 고려하여 다음 학년도 학급을 편성하는 프로그램입니다.
이 PC에서 실행되고 웹브라우저로 사용합니다. 로그인, 유료 API, 외부 서버가 없어도 모든 핵심 기능이 작동하며, 학생 정보는 외부로 전송되지 않습니다.
(AI 보조 기능은 선택 사항이며 기본값은 꺼짐입니다.)

---

## 1. 설치와 실행 (Windows)

### 방법 A — 설치 파일 (권장, Python 불필요)
1. 저장소 오른쪽의 **[Releases](https://github.com/ykm871201-design/class-mate/releases/latest)** 에서 **`ClassMate-Setup-버전.exe`** 를 내려받습니다.
2. 더블클릭하여 설치합니다. 관리자 권한 없이 사용자 계정에 설치되며, 바탕화면·시작 메뉴에 **‘학급 편성 도우미’** 가 생깁니다.
   - 처음 실행할 때 **‘Windows의 PC 보호’** 창이 뜨면 **추가 정보 → 실행**을 누르세요 (코드 서명 인증서가 없는 프로그램이라 나타나는 경고입니다).
3. ‘학급 편성 도우미’를 실행하면 검은 창이 뜨고 웹브라우저가 자동으로 열립니다. 검은 창을 닫으면 종료됩니다.
4. 설치판의 자료 저장 위치는 `%LOCALAPPDATA%\ClassMate\data` 입니다. 프로그램을 제거해도 학생 자료는 지워지지 않습니다.

설치 없이 쓰려면 같은 Releases 페이지의 **`ClassMate-Portable-버전.zip`** 을 풀고 `ClassMate.exe` 를 실행하세요.
이미 실행 중일 때 다시 실행하면 새로 켜지 않고 브라우저만 다시 엽니다.

### 방법 B — 소스에서 실행 (Python 사용)

| 단계 | 할 일 |
|---|---|
| ① | 이 폴더(`class-planner`)를 PC의 원하는 위치에 복사합니다. (예: `문서\학급편성`) |
| ② | **Python 3.9 이상**이 없다면 <https://www.python.org/downloads/windows/> 에서 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"에 꼭 체크**하세요. |
| ③ | 폴더 안의 **`실행하기.bat`** 을 더블클릭합니다. 검은 창이 뜨고 잠시 후 웹브라우저가 자동으로 열립니다. |
| ④ | 사용을 마치면 검은 창을 닫습니다. 자료는 작업할 때마다 자동 저장되어 있습니다. |

- 엑셀 처리에 필요한 구성요소(openpyxl)는 `vendor` 폴더에 들어 있어 **추가 설치나 인터넷 연결이 필요 없습니다.**
- 브라우저가 자동으로 열리지 않으면 검은 창에 표시된 주소(보통 `http://127.0.0.1:8765/`)를 브라우저에 입력하세요.
- 바탕화면에서 바로 실행하려면 `실행하기.bat` 을 오른쪽 클릭 → **바로 가기 만들기** → 바로 가기를 바탕화면으로 옮기세요.
- 프로그램은 이 PC(127.0.0.1)에서만 접속할 수 있습니다. 같은 네트워크의 다른 PC에서는 접속할 수 없습니다.
- macOS/Linux: 터미널에서 `./run.sh` (또는 `python3 server.py`).

## 2. 처음 써 보기 (실제 학생 자료 없이)

1. **① 프로젝트** 화면에서 **🧪 가상 예시 프로젝트 만들기**를 누릅니다.
   - 가상 학생 122명(편성 대상 120명, 전출 예정 2명, 전입 예정 2명 포함, 동명이인 2쌍), 현재 4개 반 → 새 5개 학급(가반~마반, 목표 24·최대 26명)
   - 여러 특성(학습 수준, 기초학습 지원, 활동성, 자기조절·또래 관계·생활지도 지원 필요 정도, 리더 성향, 개별 교육 지원, 한국어 지원, 예체능 관심, 교사 태그, 메모)
   - 관계 조건 10개(반드시 다른 반, 4명 모두 다른 반, 같은 반, A-B·B-C로 이어지는 3명 같은 반, 6명 중 반마다 최대 2명, 특정 쌍끼리 다른 반, 가급적 조건 등)와 지정 배정 1명
2. **⑤ 자동 편성** → **조건 충돌 검사** → **▶ 자동 편성 시작** (보통 수 초~수십 초)
3. **⑥ 결과 비교 및 조정**에서 대안을 비교하고 학생을 끌어 옮겨 봅니다.
4. **⑦ 저장 및 출력**에서 확정 → 새 번호 부여 → 엑셀 내보내기를 해 봅니다.

`samples` 폴더에는 **엑셀 입력 양식**과 **가상 학생 120명 예시 엑셀**이 들어 있습니다. 예시 엑셀을 새 프로젝트에 불러오면 엑셀 불러오기 과정을 체험할 수 있습니다
(특성 열까지 불러오려면 먼저 ‘특성 항목 관리’에서 해당 항목을 켜 두세요).

### 꼭 알아 둘 원칙
- **학생 ID로 학생을 구분**합니다. 이름은 식별자로 쓰지 않으므로 동명이인도 정확히 구분됩니다.
- **미입력은 ‘0’, ‘낮음’, ‘해당 없음’과 다릅니다.** 미입력 학생은 균형 계산에서 따로 세고, 미입력이 많은 항목(20% 이상)은 ‘자료 부족’으로 평가의 한계를 안내합니다. 다중 선택에서 아무것도 해당하지 않으면 ‘해당 없음’을 따로 고릅니다.
- 특성은 **교사가 입력한 값만** 사용합니다. 프로그램이 특성을 추정·진단하지 않으며, **자유 메모는 편성 계산에 자동 반영되지 않습니다.**
- **필수 조건(반드시)** 은 항상 지키며 프로그램이 스스로 완화하지 않습니다. **균형 조건(가급적·특성 분포 등)** 은 중요도에 따라 가능한 한 맞춥니다.
- 형제자매·쌍둥이·친구 같은 **사유만으로 같은 반/다른 반을 정하지 않습니다.** 교사가 지정한 조건만 따릅니다.
- 학생 개인을 하나의 ‘좋고 나쁨 점수’로 합산하거나 순위를 매기지 않습니다.

## 4. 자동 편성은 어떻게 이루어지나요?

1. **조건 충돌 사전 검사**: 전체 정원 부족, 같은 학생의 서로 다른 학급 고정, 같은 반·다른 반 충돌(예: A-B, B-C는 같은 반인데 A-C는 반드시 다른 반 — 연결 경로까지 표시), 같은 반 그룹이 최대 인원보다 큼, ‘모두 다른 반’ 학생 수 > 학급 수, 서로 얽힌 ‘다른 반’ 학생 수 > 학급 수, 고정만으로 정원 초과 등을 찾고 **관련 학생과 조건, ‘해당 설정으로 이동’ 버튼**을 보여 줍니다.
2. **필수 조건을 모두 만족하는 배치 찾기**: 되돌아가며 찾는 방식으로 필수 조건을 만족하는 첫 배치를 찾습니다. 모든 경우를 확인했는데도 없으면 **“조건상 불가능(모든 경우를 확인함)”**, 탐색 한도 안에 못 찾으면 **“제한 안에서 찾지 못함(불가능하다고 확인된 것은 아님)”** 으로 구분해 안내합니다.
3. **균형 개선**: 필수 조건을 깨는 이동·교환은 아예 시도하지 않으면서, 한 명 이동·두 명 교환을 반복해 균형 조건을 개선합니다.
   - 학급별 기대 인원 = 범주 전체 인원 × (학급 목표 인원 ÷ 목표 인원 합) → **학급 정원이 달라도 규모에 비례**하여 비교
   - 선택지·단계별 인원 분포를 맞추므로 **평균만 같고 상·하위 학생이 몰리는 문제**를 막습니다(학습 수준은 ‘단계별 분포 + 평균’).
   - 항목마다 범주 수로 나누고, 평균은 표준화하여 **선택지가 많거나 숫자 범위가 넓은 항목이 과도하게 영향을 주지 않게** 합니다. 범위가 넓은 숫자 항목은 5개 구간으로 묶어 계산합니다.
4. **서로 다른 대안 최대 3개**: 학급 이름만 바뀐 결과는 같은 편성으로 보고(학급을 최적으로 짝지은 뒤 비교), 충분히 다른 대안만 제시합니다. 조건상 대안이 부족하면 실제로 찾은 개수만 보여 줍니다.
5. **재현성**: 시간 제한이 아니라 반복 횟수로 진행하므로 **같은 자료와 같은 난수 시드면 같은 결과**가 나옵니다.
6. 최종 결과는 별도의 검사 모듈로 필수 조건을 다시 확인하며, 위반이 있는 결과는 내보내지 않습니다.

## 5. 엑셀 불러오기와 내보내기

**불러오기**: ② 학생 명단 → **📄 엑셀 입력 양식 받기**(학생 명단·특성 입력 안내·학생 간 관계·관계 입력 안내·입력 예시 시트) → 작성 → **📥 엑셀에서 불러오기**
- 학교 양식의 열 이름이 달라도 **열 연결 화면**에서 연결합니다(예: ‘성명’ → ‘이름’, ‘학번’ → ‘학생 ID’). 흔한 이름은 자동으로 연결해 둡니다.
- **검사하기(미리보기)** 에서 필수값 누락, 학생 ID 중복, 선택지에 없는 값, 숫자 범위 오류, 명단에 없는 학생을 가리키는 관계, 이미 불러온 같은 자료(중복 불러오기)를 **행 번호와 수정할 내용**으로 보여 줍니다.
- 오류가 있는 자료는 조용히 버리거나 임의 값으로 바꾸지 않습니다. 파일을 고쳐 다시 올리거나, ‘오류가 있는 N개 행은 제외하고 불러오기’를 **직접 선택**해야만 진행됩니다.
- .xlsx(권장)와 .csv 를 지원합니다. 예전 .xls 파일은 엑셀에서 .xlsx 로 다시 저장해 주세요.

**내보내기**: ⑦ 저장 및 출력 → 최종 확정 → 새 번호 부여 → **① 포함될 항목 미리보기** → **② 엑셀 파일 받기**

## 7. AI 보조 기능 (선택, 기본값 꺼짐)

AI는 **요청 해석, 편성 조건 제안, 결과 설명, 수정 조건 변환**에만 쓰입니다. 실제 배정은 편성 프로그램이 필수 조건을 검증하며 계산하고, 교사가 확인하여 적용합니다. AI 없이도 다른 모든 기능은 그대로 작동합니다.

| 기능 | 위치 | 하는 일 |
|---|---|---|
| 문장으로 편성 방향 설정 | ④ 관계 및 편성 조건 | 요청 문장을 실제 존재하는 특성 항목과 연결하여 균형 조건(반영 여부·방식·중요도)과 특성 조합을 제안. **현재 설정 → 제안 설정**을 비교해 고른 것만 적용. 꺼져 있거나 없는 항목은 ‘자료 없음’으로 안내, 모호한 요청은 필수 조건으로 바꾸지 않음. |
| 결과 설명 | ⑥ → 설명·수정 제안 | 프로그램이 계산한 사실 문장(인원·분포·조건 충족)을 쉽게 정리. **AI 설명에 계산되지 않은 숫자가 있으면 거부**하고 프로그램 계산 결과를 보여 줌. 확인되지 않은 원인은 ‘가능성’으로 표시. ‘원인 확인(재계산)’ 버튼은 실제 재계산으로 원인을 확인. |
| 수정 제안 | ⑥ → 설명·수정 제안 | “3반의 학습 지원 부담을 조금 줄여줘” 같은 요청을 **수정 조건**으로 바꾸고, 알고리즘이 실제 이동·교환 후보를 계산. 이동 대상, 전후 학급 인원, 좋아지는/나빠지는 항목, 필수 조건 충족, 이동 학생 수 표시. **적용 버튼을 누르기 전에는 편성안이 바뀌지 않고, 적용 후 실행 취소 가능.** AI 없이 직접 조건을 정해 후보를 계산할 수도 있음. |
| 메모 → 태그 후보 | 특성 항목 관리 | 교사가 고른 메모에 한해 기존 선택지 중에서만 태그 후보를 제안. 교사가 확인한 것만 저장. 메모 속 이름·연락처·날짜는 가린 뒤 처리. |

**연결 방식** (화면 오른쪽 위 🤖 AI 연결 설정)
- **내장 간이 해석기**: 이 PC 안에서만 처리하는 키워드 기반의 단순 해석기. 외부 전송·비용 없음. 체험과 간단한 요청용.
- **OpenAI 호환 서버**: 이 PC에서 실행하는 Ollama·LM Studio 등(예: `http://127.0.0.1:11434/v1`) 또는 학교가 승인한 서버.
- **Anthropic Claude API**: 인터넷으로 외부 전송되며 **사용량에 따라 비용이 발생**합니다. `AI구성요소_설치.bat` 을 한 번 실행한 뒤 API 키를 입력하세요. 기본 모델은 `claude-opus-5-5` 이며, 모델이 응답을 거절할 경우를 대비한 서버 측 대체 모델 기능(fallbacks)을 켜 두었습니다.

**정보 보호**
- 외부 AI 사용 여부는 **학교의 개인정보 처리 기준**에 따라 결정하세요. 외부 전송은 설정에서 ‘외부 AI로 자료 전송 허용’을 교사가 직접 켜야만 가능합니다.
- 매번 전송 전에 **보낼 항목, 빠지는 항목, 실제로 보낼 내용 전체**를 보여 주고, 교사가 승인해야 보냅니다(미리보기 내용 = 실제 전송 내용).
- 이름 대신 임시 표기, 학급별 집계 위주로 보냅니다. 학교명·생년월일·연락처·자유 메모·관계 사유는 기본 전송 항목에서 제외됩니다. 이름을 지워도 특성 조합으로 학생을 알아볼 가능성이 있으므로 익명 정보라고 단정하지 않습니다.
- API 키는 이 PC의 `data\ai_key.secret` 에만 저장되며, 화면(브라우저)·프로젝트 파일·백업 파일에 들어가지 않습니다.
- AI 응답은 정해진 구조로 받아 **존재하는 항목·학급·선택지인지, 허용된 조건 종류·중요도인지, 고정 배정과 필수 조건을 침해하지 않는지** 검사하며, 잘못되면 아무것도 바꾸지 않습니다. 적용한 제안은 **⑦ 변경 기록**에 남고 되돌릴 수 있습니다.
- 연결 실패나 사용 한도 초과가 있어도 편성 작업과 저장된 자료는 그대로 유지됩니다.

## 10. 남아 있는 제한 사항

- **최적해 보장 아님**: 균형 개선은 반복 탐색 방식이라 ‘가장 좋은 편성’을 수학적으로 보장하지는 않습니다(필수 조건 충족은 항상 보장). ‘꼼꼼하게’로 실행하거나 시드를 바꿔 대안을 더 볼 수 있습니다.
- **불가능 증명의 범위**: 대부분의 충돌은 사전 검사와 전체 탐색으로 확인하지만, 조건이 매우 복잡하게 얽히면 탐색 한도에 걸려 ‘제한 내 미발견’으로 안내될 수 있습니다(불가능하다고 단정하지 않음).
- **원인 확인(재계산)** 도 같은 탐색 방식이므로 “더 나은 배치를 찾지 못함”은 완전한 증명이 아닙니다(화면에 그렇게 표시).
- **내장 간이 해석기**는 키워드 기반이라 복잡한 문장을 정확히 이해하지 못합니다. 제안은 반드시 확인 후 적용하세요. 외부 AI(Claude API, Ollama 등)의 실제 응답 품질은 이 환경에서 키 없이 시험하지 못했습니다(호출 형식과 응답 검증은 시험함).
- **코드 서명 없음**: 설치 파일에 코드 서명 인증서가 없어 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다(‘추가 정보 → 실행’). 학교 보안 정책상 서명되지 않은 프로그램 설치가 막혀 있으면 관리자 도움이 필요합니다.
- **동시 사용**: 한 PC에서 한 명이 쓰는 것을 전제로 합니다. 같은 프로젝트를 브라우저 창 두 개에서 동시에 고치면 나중에 저장한 내용이 남습니다.
- **실행 취소 기록**(⑥ 화면의 이동·교환·고정)은 프로그램을 끄면 사라집니다. 편성안 자체와 ‘원래 자동 편성 결과’는 저장되므로 비교·복사본으로 대신할 수 있습니다.
- **엑셀 형식**: .xls(예전 형식)는 직접 불러오지 못합니다. 병합된 머리글 등 복잡한 양식은 단순한 표로 정리한 뒤 불러오세요.
- 학생 수가 수백 명을 넘으면 계산 시간이 길어질 수 있습니다(초등 한 학년 규모 기준으로 설계).
