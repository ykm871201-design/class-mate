## 내려받기

| 파일 | 용도 |
|---|---|
| **ClassMate-Setup-버전.exe** | **설치 파일 (권장)** — 더블클릭하여 설치하면 바탕화면·시작 메뉴에 ‘학급 편성 도우미’가 생깁니다. 관리자 권한 없이 설치됩니다. |
| ClassMate-Portable-버전.zip | 설치 없이 쓰는 휴대용 — 압축을 풀고 `ClassMate.exe` 를 실행합니다. |

Python 등 다른 프로그램을 따로 설치할 필요가 없습니다. 인터넷 연결 없이 작동하며 학생 정보는 이 PC에만 저장됩니다.

### 처음 실행할 때 ‘Windows의 PC 보호’ 창이 뜨면
이 프로그램은 코드 서명 인증서가 없어 처음 실행할 때 Windows가 경고할 수 있습니다. **추가 정보 → 실행**을 누르세요.

### 사용 방법
1. ‘학급 편성 도우미’를 실행하면 검은 창이 뜨고 웹브라우저가 자동으로 열립니다. (검은 창을 닫으면 종료)
2. 처음에는 **① 프로젝트 → 🧪 가상 예시 프로젝트 만들기**로 실제 학생 자료 없이 체험해 보세요.
3. 자세한 사용법은 설치 폴더의 `사용설명서.txt` 또는 저장소의 README를 참고하세요.

자료 저장 위치: `%LOCALAPPDATA%\ClassMate\data` (프로그램을 제거해도 학생 자료는 남습니다)
